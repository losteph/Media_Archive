# 🎬 Obsidian Media Vault (Dashboards for Movies, TV, Books & Music)

**ITA:** Questo progetto trasforma Obsidian in un hub multimediale definitivo. Tramite 4 plugin custom (sviluppati per interfacciarsi con il frontmatter locale) e l'uso di Dataview, puoi gestire la tua libreria di Film, Serie TV, Musica e Libri con un'interfaccia grafica in stile Netflix/Spotify, mantenendo il 100% del controllo sui tuoi dati Markdown.

**ENG:** This project turns Obsidian into an ultimate media hub. Through 4 custom plugins (built to read local frontmatter) and Dataview, you can manage your Movies, TV Shows, Music, and Books library with a Netflix/Spotify-like graphical interface, while retaining 100% ownership of your Markdown data.

### ✨ Features
* 📺 **4 Custom Dashboards:** Dedicated views for Movies, TV Shows, Music, and Books.
* 📱 **Fully Responsive:** Grid and list layouts adapt perfectly to mobile devices.
* 📊 **Dynamic Progress Bars:** TV Shows feature auto-updating Dataview progress bars.
* 🕸️ **Automated Cast/Author Pages:** Backlink-based templates that auto-populate filmographies and bibliographies.
* 🎨 **Unified CSS:** A single, lightweight snippet rules the design across all plugins.
