## 📥 Guida all'Installazione

Per installare e far funzionare le dashboard nel tuo Vault di Obsidian, segui questi semplici passaggi:

1. **I Plugin delle Dashboard:**
   Copia le cartelle dei plugin (es. `dashboard-film`, `dashboard-serie`, ecc.) all'interno della cartella nascosta del tuo Vault:
   `tuo-vault/.obsidian/plugins/`

2. **Attivazione:**
   Apri Obsidian, vai su *Impostazioni > Plugin della community*, ricarica i plugin e attiva le varie dashboard.
